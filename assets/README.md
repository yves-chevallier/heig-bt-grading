# Logo HEIG-VD

`heig-vd.svg` is the original vector asset copied from
`~/quiz-thoughts/opendidac/web/public/heig-2020-slim-red.svg`.
The HEIG Classroom checkout contains no institutional vector logo.

The Typst template (`typst/evaluation.typ`) embeds this SVG as vectors, in its
original HEIG-VD red, with its top-left corner 15 mm from the top and left edges
of each page. No rasterization.
