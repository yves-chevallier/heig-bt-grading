# Logo HEIG-VD

`heig-vd.svg` is the original vector asset copied from
`~/quiz-thoughts/opendidac/web/public/heig-2020-slim-red.svg`.
The HEIG Classroom checkout contains no institutional vector logo.

The PDF renderer draws its SVG paths and polygons directly as PDF vectors, with
its top-left corner 15 mm from the top and left edges of each page. The PDF uses a
monochrome version of these same paths for grayscale printing. No rasterization.
